# Tep Worlds Brand Site

This is a static brand guidelines site ready for GitHub Pages.

## Deploy to GitHub Pages

1. Create a new GitHub repo (e.g., `tep-worlds-brand`)
2. Upload the contents of this folder to the repo root
3. In GitHub: Settings → Pages → Source: Deploy from branch → main → / (root)
4. Your site will be live at https://<username>.github.io/tep-worlds-brand/

## Files
- index.html — brand guidelines
- assets/logo.png — logo

Fonts load from Google Fonts (Climate Crisis, League Spartan, Sora).
